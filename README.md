<h1 align="center">Gamechanger</h1>

<p align="center">A website built for the biggest tech conference in the Balkans. The conference owner, Matija Vučković, reached out to me needing a website that would attract a large number of visitors to the event. The deadline was tight, but everything was delivered on time and as planned, and the conference ended up drawing over 1,000 visitors.</p>
